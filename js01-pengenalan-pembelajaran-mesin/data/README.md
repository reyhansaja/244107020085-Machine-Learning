  kolom sesuai modul JS01 Tugas Pendahuluan JS02: `no, nama_lengkap, jenis_kelamin,
  kota_asal, tinggi_cm, berat_kg, asal_kelas, target_ips` + turunan `imt`.
  Dibangkitkan `tugas/tugas_pendahuluan_js02.py` karena responden nyata tidak tersedia.
  Ganti dengan data asli (kolom sama), script tetap jalan tanpa perubahan.

Dataset eksternal tidak diperlukan untuk JS01; contoh data diambil dari
`sklearn.datasets` (Iris) dan sinyal EKG sintetis.
